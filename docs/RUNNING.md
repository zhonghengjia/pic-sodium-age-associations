# Running the original guarded workflows

Use an authorized private workspace with the historical relative-directory layout expected by the source code. Public copies keep original function names, model formulas and guards. Data, source bindings, plans, acceptance receipts and aggregate source files must be supplied locally; none is in this repository. Required local controls are visible in each script's context/preflight functions. Prepare a new local review binding for sanitized code; do not bypass a failing control or generate an acceptance record merely to make the code run.

1. Supply a correctly cleaned, adjudicated 3,459-row observed input and the MI configuration. `run_clean_MI.R ROOT preflight` validates setup; `ROOT mi` runs only after its local code-release gate. Apply `preserve_export_literals.py` to the new local MI exports, then independently validate the actual MI object and 50 exports.
2. Supply association `SOURCE_BINDINGS.json` to the observed input, MI object, 50 completed datasets and current data/review controls. `outcome_engine.R ROOT preflight` validates correspondence and fixed designs; `ROOT models` fits only after its local release gate. The Python separation screen consumes restricted local binary designs.
3. Set `PIC_ASSOCIATION_ROOT` and provide the prediction configuration and review controls. `prediction_engine.R ROOT preflight` validates fold/imputation setup; `ROOT models` performs repeated cross-validation after release. Repeats=5, folds=5, prediction M=10, maxit=10, donors=5, fixed seeds and bootstrap B=2,000 remain in the configuration. Bootstrap intervals condition on saved mean repeat OOF scores; they do not include retraining/fold/imputation uncertainty.
4. Generate KM and AJ estimates from authorized local follow-up inputs. KM uses complete hospital follow-up even though final curves display 0–30 days. The final Number alive display is initial group size minus cumulative recorded hospital deaths, including discharged survivors; it is not the KM risk set.
5. Supply saved aggregate source estimates to the original renderers. `render_revision.R` compares retained geometry against baseline snippets before writing revised figures. Historical figure numbers must be mapped using `FIGURE_LINEAGE.md`. The vector-text utility requires a local approved inventory and the original PDF inputs, neither included here.

The public archive provides source-code transparency. Rebuilding the private workflow requires licensed inputs, matching local controls and several unbundled display-source preparation steps. It has been statically parsed but has not been rerun on study data or visually re-rendered for this release.
